# Hydraulic Ram Lab

Interactive 3D lab of a hydraulic ram: how falling water lifts water, with no electricity or fuel.

**▶ https://ram-pump-lab.vercel.app**

> Scaffold generated from [lab-template](https://github.com/Onigam/lab-template): the application frame comes from
> [lab-kit](https://github.com/Onigam/lab-kit). Read `BRIEF.md` first, then fill `docs/research.md`
> (copy `docs/research.template.md`).

🇫🇷 [Version française plus bas](#français)

## Run locally

```bash
npm install
npm run dev
```

`npm run typecheck && npm run format:check && npm test && npm run build` is what CI runs. Every push to `main`
deploys to Vercel.
